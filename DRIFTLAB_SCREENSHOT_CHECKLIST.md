# Driftlab screenshot checklist

Capture each screen at a desktop viewport (1440 × 900) and a mobile viewport (390 × 844):

- [ ] Registration / landing — initial Team Account step, right-side Key Rules card, and jellyfish hero.
- [ ] Registration — Rules & Regulations step, reading progress, table of contents, consent lock, and print action.
- [ ] Team login — static jellyfish fallback, readable form, and team/admin links.
- [ ] Team dashboard — lilac round cards, member badges, and status text.
- [ ] Active round — dark editor/compiler palette, legible timer, and no hero/video/audio.
- [ ] Admin login — ink background, lilac text, and distinct administrator presentation.
- [ ] Admin dashboard — tab navigation, KPI/data surfaces, team consent version/time, and Competition Rules editor.

Check keyboard focus, 360 px minimum-width behavior, reduced-motion fallback, and readable status colors in each relevant capture.
